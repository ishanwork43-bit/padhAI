# Cloud service models
Infrastructure as a Service (IaaS) supplies virtual machines, storage, and networking.
The customer manages the guest operating system, application, and data; the provider
manages physical hardware. Platform as a Service (PaaS) provides a managed application
runtime, so the customer deploys code without maintaining the underlying OS.
Software as a Service (SaaS) delivers a ready-to-use application through a browser.
For example, renting a virtual server is IaaS, deploying code to a managed runtime
is PaaS, and using a hosted email application is SaaS.
