BEFORE YOU BEGIN

A few things
to know.

Useful tools work better
with clear expectations.

Do I need an API key?

Uploading, previewing, and searching notes work without an OpenAI key. AI answers and quizzes are available when the app owner configures one. Those actions can incur provider charges and run only when you explicitly request them.

Where do my notes go?

The hosted app processes uploads on its Streamlit server and holds notes and indexes in session memory. They are not saved as project files. Refreshing, disconnecting, or a server restart may lose the session. When you request AI generation, selected excerpts are sent to OpenAI. This landing page does not collect uploads.

Can I rely on every answer?

Check the source passages. The app validates source IDs and exact evidence quotes, but a matching quote does not prove that an answer or quiz question is correct. Treat PadhAI as a study aid and verify important details in your original material.

What if my PDF is scanned or the app is slow?

Scanned PDFs need OCR before upload. The first search index downloads and loads the embedding model, which can take a little longer. Hosted instances may also sleep between visits. Start with a small document and follow any error message shown in the app.
